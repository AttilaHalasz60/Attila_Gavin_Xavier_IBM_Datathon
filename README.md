## Attila_Gavin_Xavier_IBM_Datathon

## Inspiration
The recent events regarding software security of concrete technologies like PHP and SSH getting hacked, inspired us to find out more about vulnerabilities and exploits. So getting a lot of pre formatted data about said topic let us explore our curiosity by trying to make an application with real world use. We want to make a solution that makes the threat of system security more understandable to the average person while giving a glimpse of what the future may look like to the technological savvy. 

## What it does
Our application takes the given information and is able to summarize the descriptions of each vulnerability, predict new vulnerabilities and their affects, and then visualize how both the original and predicated vulnerabilities affect companies. 

## How we built it

We used jupyter notebooks using python as a base since we didn’t have time to make a full application. In the future we would most likel y improve this application by making a distinct python file and use flask to make a front end for user input and displaying our results.

## Challenges we ran into
We had to convert the csv files with gzip in order to get them on to github and still make them readable to python. In addition we ran into several issues with github, with push and pull breaking. Some of our files didn’t update properly after pulling and we had to either delete the file or re-clone the repo.
